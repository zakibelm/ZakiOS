Applique le Socle ZakiOS (`.claude/socle/REGLES.md`). Première ligne : `ZAKIOS-SOCLE v1 · PDCA`.

Rédige le plan avec les sections ci-dessous. Chemin d'enregistrement : `docs/plans/AAAA-MM-JJ-<sujet>.md`. Si tu n'as pas d'outil d'écriture, retourne le plan complet dans ta réponse et indique ce chemin sans l'écrire.

Sections :
1. **Planifier** : situation initiale, résultat attendu mesurable, contraintes, critères d'acceptation.
2. **Exécuter** : tâches courtes ; pour chacune fichiers touchés, commande de vérification, périmètre autorisé.
3. **Vérifier** : comment chaque critère sera prouvé.
4. **Agir** : quoi faire en cas d'écart, quoi standardiser.

Proportion : un changement mineur tient en quelques lignes ; n'impose pas de cycle test-d'abord à chaque tâche, seulement quand le risque le justifie. Termine en proposant l'exécution par la personne ou un agent, sans exiger de skill particulier.

Termine le plan par la ligne exacte `Fin du plan ZakiOS`.
